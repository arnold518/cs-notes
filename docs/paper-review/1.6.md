## Problem Scenario

!!! definition "Definition 1.6.1 : Problem Scenario"
    - **Dataset** :  
        We have a dataset $\mathbf{X} = \{x^{(1)}, x^{(2)}, \dots, x^{(N)}\}$ consisting of $N$ independent and identically distributed (i.i.d.) samples.
    
    - **Generation** :  
        We assume that this data is generated by some random process involving an unobserved (latent) continuous random variable $z$.

        The generative process is defined by two steps:

        1.  Sample $z$ : A value $z$ is generated from a **prior distribution** $p_{\theta^*}(z)$.
        2.  Sample $x$ : A value $x$ is generated from a **conditional distribution** $p_{\theta^*}(x|z)$.

        Here, $\theta^*$ refers to the true (but unknown) parameters of the process.

    - **Objective** :  
        We want to estimate the parameters $\theta$ (to make the model match the real data) and generate new data according to $p_\theta(x)$.
        Also, for any given datapoint $x$, we want to infer the latent characteristics $z$ that produced it.

!!! definition "Definition 1.6.2 : Key Concepts"
    - **Prior Distribution** : $p_\theta(z)$  
        The probability distribution of the latent variables $z$ *before* we observe any actual data $x$.
    - **True Posterior** : $p_\theta(z|x)$  
        The probability distribution of the latent variable $z$ *after* we have observed a specific data point $x$.
    - **Conditional likelihood** : $p_\theta(x|z)$  
        The probability of observing a specific data point $x$ given a specific latent code $z$.
    - **Marginal Likelihood** : $p_\theta(x)$  
        The probability of a data point $x$ occurring under our model, considering *all possible* latent causes $z$.

!!! concept "Concept 1.6.3 : Intractable Marginal Likelihood"
    The marginal likelihood $p_\theta(x)$ should be computed by

    $$
    p_\theta(x) = \int p_\theta(x|z) p_\theta(z) \, dz
    $$
